# SQL (MySQL) – Learning Resources & Practice

This folder contains my SQL learning materials, classroom teaching files, practical assignments, query exercises, and database practice work completed as part of the Data Science & Data Analytics course at IT Vedant.

The purpose is to maintain an organised backup of all SQL-related resources and document my progress in database management and data querying.

- Aggregate functions (SUM, AVG, COUNT, MIN, MAX)

- String functions
- Date and time functions

- Common Table Expressions (CTEs)

- Database relationships and practical queries
